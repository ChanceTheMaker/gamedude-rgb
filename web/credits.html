Credits & limitations

Peanut-GB by Mahyar Koshkouei, with CGB support from tvecera (gbc-rtc-fix), integrated and corrected for GameDude Color, including credited SameBoy contributions by Lior Halphon: MIT. MiniGB APU by Mahyar Koshkouei and Alex Baines: MIT.

Felucca hardware foundation by Leo Kuroshita and Hügelton Instruments; SMK and MusicCoach adaptations from Chance Roth / ChanceTheMaker: GPL-3.0-only. This port is GPL-3.0-only with retained third-party MIT notices.

The browser runs the same C Game Boy core as the hardware candidates. It does not emulate the JieLi chip, board timing or electronics. Sound is synthesized at frame granularity. Some games may have timing, visual or audio inaccuracies.

Game Boy and Game Boy Color; no GBA, link cable, rumble or save states. Browser cartridge RAM saves locally, keyed by cartridge SHA-256; real-time-clock state does not persist while closed. Hardware cartridge RAM is temporary. FM-1 and SMK firmware retain USB updating, Bluetooth and USB game loading, and a persistent game library. Hardware cartridges are limited to 256 KiB each.

The included diagnostic cartridge is an original test program. No commercial game ROMs or Nintendo boot ROM are bundled.
